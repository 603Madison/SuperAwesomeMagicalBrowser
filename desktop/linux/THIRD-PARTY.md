# What SuperAwesomeMagical Browser carries

- **Ladybird** (`/usr/lib/superawesomemagicalbrowser/ladybird`), built from
  <https://github.com/LadybirdBrowser/ladybird> at the tag named in `version.json`, with the changes
  in this project's `desktop/ladybird/patches`. BSD 2-Clause; the libraries it is built with keep
  their own licences (FFmpeg and, in the Ubuntu package, Qt are under the LGPL). Their sources are
  those of Ladybird's vcpkg.json at that tag.
- **Bitwarden's command-line client** (`/usr/lib/superawesomemagicalbrowser/bitwarden/bw`), the
  open-source ("oss") build from <https://github.com/bitwarden/clients>, GPL-3.0. Bitwarden is
  Bitwarden Inc.'s trademark; this browser is not a Bitwarden product.
- **Lexend**, SIL Open Font Licence (`Lexend-OFL.txt`).
- The start page photo, public domain (`start-page-photo-CREDITS.md`).
- Our own files, GPL-3.0 (`SuperAwesomeMagicalBrowser-GPL-3.0.txt`).
