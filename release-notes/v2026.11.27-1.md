SuperAwesomeMagical Browser is now **Ladybird**, the independent browser, instead of Firefox, with
**Bitwarden built in**.

- **Bitwarden in the toolbar.** The key button beside the address field, or **Ctrl+Shift+L**, fills
  in your login for the site you're on. Sign in once (email and master password, with a two-step
  code if you use one, or an API key), on bitwarden.com, bitwarden.eu or your own server; after
  that it asks only for your master password, and locks itself 30 minutes after you last use it.
- **Tabs down the left**, with Ladybird's own vertical tabs.
- **Lexend** for the interface, Ladybird's own pages, and pages that don't choose a font.
- **Ladybird's Lavender colour**, light or dark with the system, and the start page with the big
  clock over the northern lights (add and remove its shortcuts right there).
- **Ecosia** for searches, **ads and trackers blocked**, Global Privacy Control on.
- **Your bookmarks come along**: on its first start it brings over the bookmarks of the
  Firefox-based version.
- **Kept up to date**: each new Ladybird release is built, checked and released here within hours.
  This one is Ladybird 2026.48.0, the first with every published security advisory fixed.

Install the package for your system; it has everything in it.

**Fedora**: `sudo dnf install ./superawesomemagicalbrowser-2026.11.27-1.x86_64.rpm`

**Ubuntu** 24.04 and newer: `sudo apt install ./superawesomemagicalbrowser_2026.11.27-1_amd64.deb`

promises about security yet. The Android app stays on Firefox's engine (Ladybird has no Android
