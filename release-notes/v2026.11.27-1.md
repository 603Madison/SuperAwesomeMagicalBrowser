SuperAwesomeMagical Browser is now **Ladybird**, the independent browser, instead of Firefox.

- **Tabs down the left**, with Ladybird's own vertical tabs.
- **Lexend** for the interface, Ladybird's own pages, and pages that don't choose a font.
- **Ladybird's Lavender colour**, light or dark with the system, and the start page with the big
  clock over the northern lights (add and remove its shortcuts right there).
- **Ecosia** for searches, **ads and trackers blocked**, Global Privacy Control on.
- **Your bookmarks come along**: on its first start it brings over the bookmarks of the
  Firefox-based version.

Ladybird itself comes from Ladybird's own repository, so add it first. Then install this package,
which brings Ladybird with it; Ladybird's updates then come with your system's updates.

**Fedora** (and SuperAwesomeMagicalLinux):

```bash
sudo curl -fsSL -o /etc/yum.repos.d/ladybird.repo https://rpm.ladybird.org/ladybird.repo
sudo dnf install ./superawesomemagicalbrowser-2026.11.27-1.x86_64.rpm
```

**Ubuntu** 24.04 (for 26.04 and newer, use `ladybird-resolute.sources` in place of
`ladybird-noble.sources`):

```bash
sudo install -d /etc/apt/keyrings
sudo curl -fsSL -o /etc/apt/keyrings/ladybird.asc https://apt.ladybird.org/ladybird.asc
sudo curl -fsSL -o /etc/apt/sources.list.d/ladybird.sources https://apt.ladybird.org/ladybird-noble.sources
sudo apt update && sudo apt install ./superawesomemagicalbrowser_2026.11.27-1_all.deb
```
